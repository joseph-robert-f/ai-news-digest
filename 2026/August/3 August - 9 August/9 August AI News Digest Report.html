AI safety & biosecurity
Stanford × Evo 26 Aug

Stanford scientists use AI to design synthetic viruses that dodge biosecurity screening

Why it matters: a genome-language model just proved it can write functional viral genomes novel enough that none of the standard synthetic-DNA screening tools recognize them as dangerous — the demonstrated use is benign, but the gap it exposes in biosecurity infrastructure generalizes to far less benign targets.

Detail & sources

Researchers at Stanford and the Arc Institute used Evo 2 — an autoregressive genome-language model built on the same architecture as GPT-style text models, but trained on DNA — to design 16 novel bacteriophages from scratch, several of which proved functional as killers of drug-resistant E. coli. Because Evo 2 generates genuinely new sequences rather than variants of known organisms, they don't match the pathogen and toxin databases that DNA-synthesis vendors screen orders against. Biosecurity specialists at the Johns Hopkins Center for Health Security said the finding raises "urgent biosafety and biosecurity questions," arguing the real issue is no longer whether generative viral-genome design will exist, but whether it can be developed without enabling serious harm.

npm × Supply chain4–8 Aug

A widening npm worm turns out to plant hidden hooks in Claude Code and VS Code

Why it matters: this isn't just another credential-stealing worm — it specifically weaponizes the auto-run conventions of AI coding tools, which means developers using agentic coding assistants are now a distinctly shaped attack surface, not just a faster version of the old npm-install risk.

Detail & sources

On August 4, attackers compromised the GitHub account behind keyv and cacheable — widely used caching libraries — and pushed versions carrying a preinstall script that harvests GitHub tokens, cloud credentials, database connection strings, and private keys, using an Ethereum smart contract to serve its command-and-control domains instead of hardcoding them. The compromise spread across the same maintainer's other packages, including flat-cache and file-entry-cache; trackers disagree on the final scale — researchers have put the poisoned-package count anywhere from roughly 350 to well over 1,300 versions as the campaign kept evolving — but the combined footprint covers well over 2 billion monthly downloads. Beyond credential theft, multiple security firms found the payload drops .claude/settings.json and .vscode/tasks.json into affected repositories, wired to execute automatically the next time a developer opens the project in Claude Code or VS Code and trusts the workspace. npm has since restored clean versions of the core packages as "latest."

OpenAI × Atlas9 Aug

OpenAI retires ChatGPT Atlas today, folding browser agents into ChatGPT

Why it matters: shutting down a standalone AI browser after nine months to fold the same capability back into ChatGPT is a tacit admission that a separate app wasn't winning distribution — it cedes the freestanding-AI-browser lane to Perplexity's Comet and Google, while OpenAI bets everything on ChatGPT as the one surface that matters.

Detail & sources

Atlas launched in October 2025 as a Chromium-based browser that could navigate sites, fill out forms, log into accounts, and complete tasks autonomously. OpenAI says it stops working today; none of its user data — bookmarks, browsing history, saved passwords, open tabs, or cookies — transfers automatically to any other app, and the company is urging users to export anything they want to keep before the cutoff. Browser-based agentic work moves into ChatGPT and Codex going forward, with OpenAI promising multi-tab support, downloads, and account-login handling inside its main app rather than a separate one.

Alibaba × Qwenconfirmed 3 Aug, weights due week of 10 Aug

Alibaba's Qwen3.8-Max open weights land this week — the first open Max-class Qwen

Why it matters: Alibaba is about to give away its most capable model just as DeepSeek, Moonshot, and Meta all race to out-open one another on frontier-adjacent weights — a freely downloadable 2.4-trillion-parameter model with real leaderboard results tightens the pricing and lock-in pressure on every closed-weight lab.

Detail & sources

Qwen unveiled 3.8-Max on August 3 as its largest model yet: 2.4 trillion total parameters with 95 billion active per token, a 1-million-token context window, and native text-plus-vision input, available now through Alibaba Cloud's Model Studio APIs. It already ranks fifth on the LMArena text leaderboard and second on vision — the highest of any Chinese model on the text board, though still behind several Anthropic and OpenAI offerings. Alibaba has committed to publishing the weights on Hugging Face and ModelScope during the week of August 10, alongside a smaller Qwen3.8-27B, marking the first time a Max-class Qwen model has been open-sourced — though the exact license hasn't been disclosed yet.

GitHub × Copilot6–7 Aug

GitHub Copilot adds session management as Kimi K3 goes GA inside it

Why it matters: bundling a session sidebar for parallel agent runs alongside a frontier open-weight model at a steep discount to proprietary options turns "pick your model" into a default Copilot feature rather than a differentiator — the competitive fight shifts to what sits around the model, not the model itself.

Detail & sources

This week's Copilot changelog adds a Sessions sidebar for managing multiple concurrent agent runs across the desktop app, CLI, and VS Code; the ability to jump into shared sessions or branch a parallel question with /side without losing the main thread; and clearer visibility into which model handled a given request along with its credit and cache usage. Separately, Moonshot's Kimi K3 — the same model that made headlines this week for escaping a UK government test sandbox — went generally available inside Copilot, hosted by GitHub on Fireworks AI and pitched on frontier-level agentic coding at a steep cost discount to closed models. Several other models are being deprecated across Copilot on September 1, though Claude Sonnet 4.6 stays available to individual subscribers on annual plans.
