Mistral releases Large 4 weights: 1.05T parameters, 49B active, new license

Why it matters: A near-frontier open-weight model for coding is now free to self-host, but the licence changed from Apache 2.0, so legal should read it before adoption.

Detail & sources

Mistral put the weights on Hugging Face on 29 October after a 6 October API-only preview. Reported specs: multimodal, 1.05 trillion parameters, 49 billion active per token. The Mistral Ecosystem Open-Weight licence is a modified MIT licence; Large 3 used Apache 2.0. The claim that it is the best open-weight coding model is Mistral's own and independent replication was still pending. It ranked high on Hacker News on 3 November.

Security29 Oct

A trojanized Claude Code extension sat on Cursor's marketplace for about 11 hours

Why it matters: Treat IDE extensions as production dependencies: pin versions, allow-list publishers, and rotate SSH keys on any machine that ran version 2.1.313.

Detail & sources

Cursor said at most 5,000 users were affected. Researchers at Phorion reported that the build tried to plant a persistent SSH backdoor, and that removing the extension may not remove the dropped scripts. Users should move to 2.1.314. Anthropic said it did not build the malicious version. The CLI and npm package were not reported as affected. The source of the bad build is disputed: Cursor says its marketplace, other reports say Open VSX. Details come from secondary outlets; check the primary notices from Cursor and Anthropic.

SecurityOngoing

Stolen AI API keys are now resold through "transfer stations"; one case reached nearly $1M

Why it matters: Set hard spend caps and alerts on every model key today; providers may not refund charges that look like valid, authenticated use.

Detail & sources

Palo Alto Networks Unit 42 calls the pattern "AI token jacking". Exposed credentials were placed into a resale proxy within minutes. Attackers create new keys, remove billing limits and disable alerts and logging. The near-$1M figure is from one incident-response case. Other figures (a Gemini key at about $82,000 in 48 hours) come from less consistent sources. This item is background from earlier in 2026 that was circulated again on 3 November.

UK cyber chief repeats: AI-enabled attacks on critical infrastructure are likely by 2028
